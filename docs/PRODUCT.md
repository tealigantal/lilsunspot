# Product

## Product Summary

小黑子是基于 Hermes Agent 的 Windows 桌面个人 Agent。产品层负责安装、中文配置、桌面与微信会话、能力解释、安全审批、文件交付和诊断；Hermes 负责模型、工具、记忆与 Agent 循环。

## Target Users

希望直接安装使用个人 Agent、但不熟悉 Provider 参数、命令行和运行时配置的普通 Windows 用户。

## User Problems

- 模型能力和限制难以理解。
- Prompt 风格常被误认为真实运行控制。
- 桌面、微信、文件与模型设置容易出现口径不一致。
- Provider 失败常暴露技术错误而缺少恢复路径。

## Critical User Journeys

- 安装并完成首个模型配置与聊天。
- 在同一对话中调整生成控制和表达风格。
- 通过桌面或微信持续对话、上传与返还文件。
- 查看回复实际模型、参数和兼容性降级详情。
- 在高风险动作前看到审批或明确边界。

## Expected User-visible Behavior

- 普通界面只暴露可理解的产品概念，技术参数收在高级设置。
- 设置保存成功意味着下一轮真实请求会使用已解析配置。
- 不支持、服务端锁定或自动降级均显示中文原因。
- “默认”表示省略字段，让模型服务决定。
- 生成控制、表达风格、高级参数和回复详情使用高对比度亮色文字，不用低对比度灰字承载说明或状态。

## Failure and Recovery Experience

配置错误、网络失败、额度、模型不存在和参数不兼容必须分类呈现。明确的参数拒绝最多自动安全降级重试一次，用户可看到实际生效结果；其它 Provider 错误不能伪装成保存成功。

## Product Constraints

生成控制不得改变工具集、安全审批、外部发送、文件写入范围、记忆开关和凭据访问。所有入口必须复用同一解析规则。

## Non-goals

不保证所有模型参数等价，不用 Prompt 冒充运行参数，不为生成控制重写 Hermes core。

## Current State

LIL-GENERATION-CONTROL-01 已把旧 Mode 收敛为纯表达风格，并建立独立生成控制：全局、会话和单轮按字段解析；sampling、输出、推理与 Agent 迭代预算进入真实运行参数；回复详情展示实际生效、锁定、省略和一次兼容降级结果。
