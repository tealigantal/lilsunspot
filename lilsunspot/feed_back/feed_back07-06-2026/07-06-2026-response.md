# 07-06-2026 反馈回应

本次已经按这个反馈目录里的 8 条问题做了一轮安装后首启体验修复。下面逐条说明改了什么、为什么这样改，以及还需要人工确认的地方。

## 当前结论

这轮修复的目标不是继续堆新功能，而是先把安装包打开后的第一印象和首启流程拉回正常用户能理解的状态。

已经处理：

- 后台黑色控制台窗口问题。
- 首次打开时优先进入模型设置流程。
- API Key 设置说明过于简略的问题。
- 模型连接测试和保存状态不清楚的问题。
- 聊天输入框发送后不清空的问题。
- 聊天页和模式页过于临时、像调试页的问题。
- 安装包和快捷方式图标替换为反馈中指定的图片。

仍需要人工确认：

- 必须重新安装新打出的安装包，从桌面快捷方式启动，确认真的不再出现黑色后台窗口。
- 必须用真实 API Key 完成一次测试、保存、聊天、关闭重开，确认本机配置会被读取。
- 必须在一台没有开发环境的 Windows 机器上跑干净安装冒烟。

## 逐条回应

### 1. 安装后后面有黑屏窗口

已处理。

本次把正式桌面程序调整为 Windows 图形界面启动方式，并且把打包出来的本地服务程序也改成无控制台窗口。也就是说，正常用户从快捷方式打开时，不应该再看到一个不能关的黑色命令行窗口。

需要注意：这项已经通过构建链路验证，但最终还必须用新安装包实际安装后确认。

### 2. 首页太丑，无法吸引用户

已做第一轮改善。

这次没有把整个产品重做成营销页，而是把当前桌面应用改得更像一个正式工具：顶部加入小黑子图标，整体间距、卡片、按钮、状态提示和页面层次都重新整理。目标是让用户一打开就知道这是一个本地个人 AI 助手，而不是开发调试页面。

这不是最终视觉稿，后续还可以继续做品牌化和更完整的 UI 设计。

### 3. 刚安装完应该先设置，而不是先展示未连接

已处理。

现在本地服务正常启动但还没有模型配置时，桌面端会优先把用户带到“设置模型服务”流程，而不是先停在“未连接/未启动”式首页。

只有本地服务真的启动失败时，才显示修复、重新检查、诊断相关入口。

### 4. API Key 页面说明太草率

已处理。

现在 API Key 页面补了面向小白用户的步骤说明：

- 先打开服务商官网。
- 登录后在 API Keys 或密钥管理页面新建 Key。
- 复制完整 Key。
- 粘贴到小黑子里测试。
- 测试通过后自动保存到本机。

同时页面会明确说明 API Key 只保存在用户自己的电脑本机，不会在界面里回显。

### 5. 加载输出无法确认是否选择成功，且模式切换不符合横向滚动想法

已做 UI 级修复。

输出风格页现在会自动加载，不再要求用户先点“加载输出风格”。模式选项改成横向卡片列表，并且会清楚标出当前已选择的风格。切换成功后也会有明确状态提示。

本次只做“选择体验”修复，完整的三滑杆和 prompt 编译仍然留到后续 P1 任务。

### 6. 聊天界面丑，发送后输入框没有清空

已处理。

聊天页现在改成正常消息流：

- 用户消息和小黑子回复分开显示。
- 当前模型会显示在聊天页顶部。
- 发送成功后输入框会自动清空。
- 如果聊天失败，会显示普通中文错误和建议，不直接丢原始技术信息给用户。

这轮没有验证真实 API Key 聊天闭环，真实聊天还需要安装后人工测试。

### 7. API Key 每次都要重新搞，应该保存在用户本机

已加强体验表达和前端状态。

后端原本已经有保存能力，会把 provider 和 API Key 写到小黑子自己的本机数据目录。本次主要修的是用户感知：测试通过后会明确显示“已保存到本机”，并说明关闭重开后会自动读取。

同时，保存成功后前端会清空内存里的 API Key，避免继续停留在输入框里。

还需要人工确认：用新安装包真实保存一次 API Key，然后关闭重开，确认不需要重新填写。

### 8. 使用 image-6.png 作为安装包和快捷方式图标

已处理。

本次已经把 `image-6.png` 转成桌面端使用的图标，并接入安装包配置。应用顶部也使用了同一张图作为小黑子视觉标识。

需要用新安装包安装后确认桌面快捷方式和安装包显示的图标是否符合预期。

## 下一步建议

下一步应该继续做干净 Windows 安装冒烟，而不是继续加新功能。

建议测试顺序：

1. 卸载旧版本或换干净 Windows 用户环境。
2. 安装新生成的 `Lilsunspot_0.1.0_x64-setup.exe`。
3. 从桌面快捷方式打开。
4. 确认没有黑色后台窗口。
5. 完成模型服务选择、API Key 测试和保存。
6. 发送一条真实聊天消息。
7. 关闭小黑子后重新打开，确认模型配置仍在。

如果以上流程通过，再回到发布级 `check_release.ps1` 和正式 clean install checklist。
